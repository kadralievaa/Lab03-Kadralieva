1. Результат одинаковый, это одно и то же. `x += 5;`просто короткая запись `x = x + 5;`. (`+=`, `-=`, `*=`, `/=`, `%=`) удобнее использовать, потому что код короче и читается легче.
2. `x++` сначала отдаёт старое значение, потом увеличивает x.
`++x` сначала увеличивает x, потом отдаёт новое значение.
Если `x++` или `++x` стоят отдельной строкой, разницы нет, оба просто увеличивают переменную на 1. Она видна только когда результат сразу используется в выражении.
3. Всегда `bool`, то есть `true` или `false`. Например, `5 > 1` даёт `true`, `10 == 5` даёт `false`. Поэтому результат сравнения можно сразу записать в переменную типа `bool`.
4. Это когда C# не вычисляет второй операнд, если результат уже понятен по первому.
в `a && b`, если `a` = false, то `b` не проверяется (результат и так false);
`a || b`, если `a` = true, то `b` не проверяется (результат и так true).
Пример: `if (list != null && list.Count > 0)` если список пустой, то второе условие даже не будет проверяться, и мы не получим ошибку.
5. Приоритет операций
1. `*` и `/` — раньше
2. `+` и `-` — позже

`2 * 3 = 6`
`4 / 2 = 2`
`10 - 6 + 2 = 6`
Проверка кодом даёт тот же результат `6`.
6. Потому что так быстрее, читающий сразу видит, что имел в виду автор, и не должен вспоминать приоритеты операторов. Это уменьшает шанс ошибок при изменении кода. Например, `(5 > 3 && 2 < 4) || false` читается понятнее, чем `5 > 3 && 2 < 4 || false`, хотя результат одинаковый.
